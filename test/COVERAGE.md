# Scientific test coverage

Use the [test guide](README.md) to run these checks or add a case. This map links scientific requirements to their assertion owners and states what the connected data does and does not exercise.

The names below match the decisions in the [QC matrix](../docs/qc_matrix.md). Each row names the component tests that own its assertions. Unit tests check scientific calculations and boundaries; integration tests check actual stage execution. All R tests use the pinned analysis image. Exact boundary combinations stay in small constructed tests; the main connected fixture stays at four libraries and covers IGH/TRB assembly through publication.

The [reviewed record table](data/expected/expected_records.tsv) anchors the 21 native records before arithmetic reconstruction: annotation return, V/J genes, individual QC failures, qualified C genes, representative links and donor/scope clone partitions. The [fixture guide](data/README.md#reviewed-record-outcomes) explains the review basis and limitations. Growing the read cohort is unnecessary for exact predicate boundaries or fitting a large donor population. Assembly sensitivity, sequencing-error robustness and biological prevalence remain outside acceptance.

[All-locus grouping](components/grouping/unit/test-retained_sequences.R) checks all six input orders of a constructed duplicate and backbone interaction at every locus: two records on different backbones carry identical DNA, and one of their backbones also holds a lower-support alternative. Native recovery of that combination remains unproven. `trust-airr.pl` in the configured TRUST4 image substitutes alternative CDR3s into each contig and writes indexed identifiers, but it does not establish that full sequences are unique across contigs, and the 21 retained public native records have no repeated full sequence. Resolving the question needs a native constructed recovery of the combination or an invariant in the pinned assembler that rules it out. The constructed regression protects the grouping contract without making an assembly-sensitivity claim.
